Medicines API

Read-only JSON data on FDA-approved medicines for HIV, ADHD and diabetes: brand and generic names, drug classes, form, dosing, manufacturer, approval dates and sources. Use it from any website, app or script.

__N_MEDS__ medicines __N_CLASSES__ drug classes 3 conditions v__DATA_VERSION__ data, __RELEASED__

Quick start

Every endpoint is a static JSON file. Send a plain GET request: no sign-up, no API key and no special headers. Requests from browsers are allowed from any website (CORS).

Base URL __BASE__

JavaScript

const res = await fetch("__BASE__/medicines/biktarvy.json");
const { data } = await res.json();
console.log(data.brandName, "-", data.genericName);
// Biktarvy - bictegravir, emtricitabine, and tenofovir alafenamide

Command line

curl __BASE__/conditions/adhd.json

Python

import requests
meds = requests.get("__BASE__/medicines.json").json()["data"]
insulins = [m for m in meds if "insulin" in m["drugClass"].lower()]

Endpoints

PathReturns
GET/index.jsonAPI root: data version, counts and every endpoint URL.
GET/medicines.jsonEvery medicine with summary fields (id, names, condition, class, status, url). Use it for lists and search.
GET/medicines/{id}.jsonOne medicine, full record, plus related: other medicines in the same class. Example: /medicines/ozempic.json
GET/conditions.jsonThe three conditions (hiv, adhd, diabetes) with counts.
GET/conditions/{condition}.jsonEvery medicine for one condition, full records, plus its drug classes.
GET/classes.jsonEvery drug class with its id and medicine count.
GET/classes/{classId}.jsonEvery medicine in one class. Example: /classes/diabetes-sglt2-inhibitor.json
GET/openapi.jsonOpenAPI 3.1 description, for Postman, Swagger or code generators.

Medicine IDs are lowercase slugs of the brand name (biktarvy, vyvanse, mounjaro) and never change. A path that doesn't exist returns HTTP 404.

Medicine fields

FieldMeaning
idStable ID, also used on the website (#biktarvy)
conditionhiv, adhd or diabetes
brandName, genericNameUS brand name and active ingredient(s)
drugClass, classIdDrug class name and its ID for /classes/{classId}.json
formulation, route, dosingFrequencyForm (tablet, pen …), how it's taken, how often
manufacturerCompany that markets the brand in the US
approvalDate, approvalYearFDA approval (date where known)
statusAvailable or Discontinued (US brand)
description, notesShort plain-English summary and extra notes
attributesCondition-specific details, e.g. controlledSubstance (ADHD), diabetesType, abbreviation and completeRegimen (HIV)
sourceUrl, linksWhere the record comes from, and links to this record, its condition, class and website page

Versions and updates

The /v1/ paths stay compatible: fields may be added but won't be removed or renamed. Breaking changes would get a new /v2/. Check dataVersion in any response to see when the data last changed, and cache responses for at least an hour.

Mirror

The same files are mirrored on the jsDelivr CDN, for example __CDN__/medicines/biktarvy.json. Add @v2.0.0 instead of @main to pin a release that never changes.
